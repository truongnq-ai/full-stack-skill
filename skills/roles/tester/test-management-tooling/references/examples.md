# Examples — Test Management Tooling

## Example 1: Zephyr to Jira Sync
**Action**: A QA Engineer writes a Test Case in markdown.
**Tooling**: An agent uses the Jira/Zephyr MCP server to parse the markdown and automatically create a Zephyr Scale Test Case linked to `US-42`.
**Result**: Single source of truth. Developers can see the linked test cases directly on their Jira board without opening QA spreadsheets.
