# Writer: Documentation Sprint

> **Trigger**: Use at the end of a sprint or when documentation is flagged as outdated.
> **Tools**: Markdown editor, Swagger/OpenAPI generators.

## Step 1 - API Documentation
Auto-generate or manually update API specifications based on recent code changes.
- **Skills**: skills/roles/writer/api-documentation/SKILL.md
- **Fallback**: If auto-generation fails, parse the route definitions manually.

## Step 2 - Technical Writing
Write user guides, developer onboarding docs, and summarize release notes.
- **Skills**: skills/roles/writer/technical-writing/SKILL.md, skills/roles/writer/docs/SKILL.md, skills/roles/writer/summary/SKILL.md

## Step 3 - Content Audit Checkpoint
Review content for clarity, tone, and technical accuracy.
- **Skills**: skills/roles/reviewer/content-audit/SKILL.md
- **Checkpoint**: Present the documentation diffs to the user for final review.

## Step 4 - Output
- **Exit Criteria**: Documentation is merged, published, and accessible to end-users/developers.

> **Required Skill**: `skills/roles/writer/documentation-sprint/SKILL.md`
